# 🎓 AI-Powered University Student Support Chatbot

An intelligent AI-powered chatbot designed to help university students get instant answers to their academic and administrative questions.

The chatbot acts as a virtual university assistant, providing information about academics, examinations, admissions, fees, scholarships, campus facilities, and university announcements.

## 🚀 Project Overview

University students often struggle to find accurate and timely information about university procedures, academic schedules, examination notices, and other important updates.

Our AI-powered chatbot aims to solve this problem by providing a centralized, intelligent, and user-friendly student support platform available 24/7.

## ✨ Key Features

- 🤖 AI-powered conversational assistant
- 📚 University information and FAQ support
- 📄 PDF and document-based question answering
- 🔍 Intelligent document search using RAG
- 🌐 Multilingual support (English, Hindi, and Hinglish)
- 📢 University announcements and notifications
- 👨‍🎓 Student dashboard
- 🛠️ Admin dashboard for managing university information
- 🧑‍💼 Human support escalation
- 💬 Chat history and conversation management

## 🧠 AI Technology

The chatbot is designed around Retrieval-Augmented Generation (RAG).

It retrieves relevant information from university documents and uses an AI model to generate context-aware answers.

## 🛠️ Technology Stack

| Component | Technology |
|---|---|
| Frontend | React.js |
| Styling | Tailwind CSS |
| Backend | Python / FastAPI |
| AI Integration | Gemini / OpenAI API |
| RAG | Embeddings and Vector Database |
| Database | PostgreSQL / Firebase |
| Authentication | Firebase Auth |
| Version Control | Git and GitHub |
